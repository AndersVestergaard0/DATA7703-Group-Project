# DATA7703-Group-Project
This is the repo for our group project on malaria detection using machine learning, in the course DATA7703.

## Structure
```
notebooks/
  00_eda.ipynb            Dataset download, image metadata extraction, EDA plots. Writes data/raw/image_metadata.csv.
  01_data_split.ipynb     Patient-level train/val/test split. Writes the frozen manifest.
  02_baseline_svm.ipynb   Course baseline: PCA + linear SVM (32x32 inputs).
  03_cnn.ipynb            Small CNN (128x128 inputs).
  04_resnet18.ipynb       ImageNet-initialised ResNet-18, same inputs/split as the CNN.
src/
  preprocessing.py        Shared image loading/padding/scaling used by every model notebook.
data/
  raw/                    Official NLM patient-to-cell mapping CSVs, plus image_metadata.csv generated by 00_eda.ipynb.
  splits/patient_split.csv  Frozen split manifest (filename, patient_id, category, split). Generated by 01_data_split.ipynb.
```

## Rules
- **Don't recompute the split.** `01_data_split.ipynb` is the only notebook that should write `data/splits/patient_split.csv`. Every other notebook loads it.
- **Fit preprocessing stats (PCA, normalization) on the training split only**, then apply to val/test.
- Preserve aspect ratio when resizing — pad to a square, don't distort via direct resize.

## How to run
### 1. Create virtual environment
```
python3 -m venv venv
```

### 2. Activate virtual environment
```
# macOS/Linux
source venv/bin/activate
# Windows (CMD)
venv\Scripts\activate.bat
```

### 3. Install dependencies
```
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Run notebooks in order
Run `notebooks/00_eda.ipynb` first (downloads the dataset, writes `data/raw/image_metadata.csv`), then `notebooks/01_data_split.ipynb` (writes `data/splits/patient_split.csv`), then any of the model notebooks.
